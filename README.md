# Accessible Assignment Companion

This project was built for IS 219 as a frontend-focused portfolio application.

## What the project is

Accessible Assignment Companion is a responsive web app for college students that combines assignment tracking with a supportive virtual companion. It is designed to reduce cognitive overload through clear assignment organization, calm visual design, and accessibility-first UX patterns.

## Why I built it

I built this project to create a believable, polished product that addresses a real student pain point: stress and executive overload when managing academic tasks. The goal was to deliver a focused solution that is lightweight, practical, and supportive rather than feature-heavy.

## What skills or technologies it demonstrates

- React + TypeScript application architecture
- Frontend-only product design and implementation
- Responsive layout and component-based UI structure
- Accessibility implementation (semantic structure, keyboard-friendly interactions, visible focus states, reduced motion support, text scaling, contrast-aware theming)
- UX-focused state modeling (workload labels, companion emotional states, non-punitive feedback)
- Production deployment workflow with GitHub Pages

This project aligns with my target role in frontend/product development by demonstrating that I can translate user needs into a complete, accessible, production-ready interface. It shows practical skills in building maintainable React experiences, making intentional UX decisions, and shipping a polished application from concept to deployment.
